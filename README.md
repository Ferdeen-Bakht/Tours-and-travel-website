# Tours and Travel Website

A static travel booking website built with HTML, CSS, and Bootstrap. The project presents a tour agency landing page for booking package tours, renting cars, and accessing travel information such as hotel and flight registration.

## Overview

This repository contains a front-end website for a fictional travel company called "FAST TOURS AND TRAVELS." It includes multiple pages for:

- home page with hero image carousel
- package tours with destination cards and booking modals
- car rental service with vehicle availability table
- information desk for hostel and flight registration forms

## Features

- Responsive navigation bar across all pages
- Bootstrap-based layout and styling
- Promotional landing page with image slider
- Country-wise and activity-based tour cards
- Booking details shown in modal popups
- Car rental catalog with model, availability, and booking actions
- Travel information desk with hostel and flight forms
- Contact/footer section with business information

## Project Structure

- `index.html` — home page with carousel, tour packages, and booking modals
- `package.html` — package tour listings and detailed booking information
- `car.html` — rental car catalog and reservation table
- `info.html` — hostel and flight registration forms
- `img1.png`, `img3.jpg`, `img6.jpg` — homepage images
- `LICENSE` — project license
- `README.md` — project documentation

## Technologies Used

- HTML5
- CSS3
- Bootstrap 4
- JavaScript and jQuery (Bootstrap components)
- External image assets and CDN-hosted styling/scripts

## How to Run

Because this is a static website, you can open it directly in a browser.

Option 1:
- Open `index.html` in any modern browser.

Option 2 (local web server):

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Pages Included

### Home
- branded navigation
- promotional slideshow
- overview text about France tours and services

### Package Tours
- destination cards such as Paris, Lyon, Bordeaux

- hostel registration form
- flight booking form

## Notes

- This is a front-end-only website and does not include backend database integration.
- Booking buttons and forms are demo UI elements and do not process real reservations.
- The website uses Bootstrap CDN assets, so internet access is required when loading the page for the first time.
